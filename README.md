# QrtrViewers

This package provides the class QuarterExaminerViewer, which resembles the SoQtExaminerViewer and the SoXtExaminerViewer classes, providing user interactivity on top of the QuarterWidget.
It's requirements are Qt6, Quarter, and Coin. 

In addition the the library, two test programs are build:
* cone:        tests basic functionality by displaying one cone
* Sierpinski:  tests performance with a more complicated scene graph, a sierpinsky cube.
